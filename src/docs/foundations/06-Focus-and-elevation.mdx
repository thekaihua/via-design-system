# Focus and elevation

## Focus

Every focusable element shows a **3 px ring with a 2 px gap** that follows its shape,
on `:focus-visible` only. The global stylesheet applies it by default:

```css
:focus-visible {
  outline: var(--via-focus-width) solid var(--via-semantic-focus-ring);
  outline-offset: var(--via-focus-gap);
}
```

Never remove it. Components may tune `outline-offset` only to keep the 2 px gap visible.
