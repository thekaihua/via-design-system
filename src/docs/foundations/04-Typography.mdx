# Typography

**Nunito** (400, 700) for UI and reading text, **Roboto Slab** (400) for headings
18 px and up, **JetBrains Mono** for code. All three are open-source (SIL OFL) and
bundled from npm, so nothing loads from a third-party CDN. Headings stay at
Regular: no bold slab.

## Families

<FontFamilies />

Chinese, Japanese, Korean and Arabic fall back to the `via.font.locale.*` Noto
families, which the app loads only for those locales.
