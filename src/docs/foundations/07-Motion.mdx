# Motion

Short and functional. **Feedback** (120 ms) for hover and press, **transition** (200 ms) for
state changes, **overlay enter/exit** (240/160 ms) for dialogs, menus and toasts. With
`prefers-reduced-motion: reduce`, every duration becomes 0 ms.
